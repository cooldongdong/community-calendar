# g0v 社群行事曆

g0v 社群活動的入口：什麼時候、在哪裡、能不能訂閱。

網站：<https://g0v.github.io/community-calendar/>（[活動搜尋](https://g0v.github.io/community-calendar/events/)、[月曆](https://g0v.github.io/community-calendar/calendar/)、[訂閱](https://g0v.github.io/community-calendar/subscribe/)）

## 訂閱日曆

| 日曆 | 網址 | 收什麼 |
|---|---|---|
| 揪松團活動 | `https://g0v.github.io/community-calendar/jothon.ics` | 只有揪松團主辦的：黑客松（大松）、AI Monday、放輕松、跑咖松 |
| 所有社群活動 | `https://g0v.github.io/community-calendar/all.ics` | 共筆上的所有活動。共筆開放社群自由填寫，**內容未經審核** |

揪松團各系列也有自己的一份，完整清單在[訂閱頁](https://g0v.github.io/community-calendar/subscribe/)。

## 資料從哪來

| 來源 | 收什麼 |
|---|---|
| 揪松團「[大松小松活動訊息](https://g0v.hackmd.io/@jothon/event)」共筆 | 社群自由填寫的所有活動，每天同步一次 |
| [AI Monday](https://g0v.github.io/AI-Monday/) 工作小組維護的資料 | AI Monday、國會松、COSCUP 的 AI 議程 |

**這裡是累積保存，不是共筆的鏡像。** 共筆會定期清掉過期的活動，但這裡一筆都不刪，所以過去的活動也查得到。

## 想新增或修改活動

- **寫在共筆上**：照共筆最上面的活動範本填，隔天就會出現在這裡
- **在網站上**：活動頁的「修改這筆」，或[新增活動](https://g0v.github.io/community-calendar/submit/)。填完會送到 GitHub，管理員確認後更新；沒有 GitHub 帳號也可以寄信
